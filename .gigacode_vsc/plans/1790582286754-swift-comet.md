# План: Фикс карусели и логина на сервере

## Проблема 1: Карусель не показывается

**Корень причины:** В `frontend/src/pages/public/` лежат **два** файла HomePage:
- `HomePage.tsx` (новое, с Swiper)
- `HomePage.js` (старое, скомпилированное)

Vite/TSC путаются при наличии двух файлов с одинаковым именем. Команда `npm run build` (`tsc && vite build`) может:
- Использовать старый `HomePage.js` вместо `HomePage.tsx`
- Или упасть с ошибкой компиляции TSC

**Решение:** Удалить `HomePage.js` — он дубликат и мешает сборке.

## Проблема 2: "Ошибка входа" при логине

**Корень причины:** LoginModal вызывает `authApi.loginUnified()` → POST `/api/v1/auth/login-unified`.
Бэкенд ищет пользователя `pahankov@mail.ru` в БД.

Суперпользователь создаётся автоматически только при **первом** деплое через GitHub Actions (sync SQLAlchemy в deploy.yml). Но deploy ещё не запускался, потому что не настроен секрет `DATABASE_URL` в GitHub.

Возможные сценарии:
1. Суперпользователь **не создан** — бэкенд возвращает 401 "User not found"
2. Суперпользователь создан вручную ранее, но с **другим паролем**

**Решение:** Создать суперпользователя на сервере напрямую через Python-скрипт (sync SQLAlchemy, без timezone-ошибок).

## План действий

### Шаг 1: Удалить HomePage.js
```bash
rm online-booking/frontend/src/pages/public/HomePage.js
```

### Шаг 2: Создать скрипт для создания суперпользователя на сервере
Файл: `online-booking/backend/create_superuser_sync.py`

Использует sync SQLAlchemy (как в deploy.yml), чтобы не было timezone-ошибок.

### Шаг 3: Запустить скрипт на сервере
```bash
cd /var/www/beauty-specialist/online-booking/backend
source venv/bin/activate
python create_superuser_sync.py
```

### Шаг 4: Пересобрать frontend
```bash
cd /var/www/beauty-specialist/online-booking/frontend
npm ci
npm run build
cp -r dist/* /var/www/beauty-specialist/frontend/dist/
```

### Шаг 5: Перезапустить frontend (если нужен nginx reload)
```bash
systemctl restart nginx
```

## Итоговый порядок на сервере

```bash
# 1. Удалить старый JS-файл
rm /var/www/beauty-specialist/online-booking/frontend/src/pages/public/HomePage.js

# 2. Запустить скрипт суперпользователя (ИСПОЛЬЗУЙ create_superuser_sync.py, НЕ create_superuser.py!)
# create_superuser.py использует async SQLAlchemy + psycopg2 → ошибка
# create_superuser_sync.py использует sync SQLAlchemy → работает
cd /var/www/beauty-specialist/online-booking/backend
source venv/bin/activate
DATABASE_URL="postgresql+psycopg2://postgres:Sug%40r2026%21@localhost:5432/online_booking" python create_superuser_sync.py

# 4. Пересобрать frontend
cd /var/www/beauty-specialist/online-booking/frontend
npm ci
npm run build
cp -r dist/* /var/www/beauty-specialist/frontend/dist/

# 5. Перезапустить
systemctl restart beauty-backend
systemctl restart nginx
```
