# План восстановления: masters.py и фикс deploy.yml

## Проблема 1: masters.py удалён
Файл `app/modules/admin/masters.py` удалён на сервере по ошибке (`rm masters.py`). Бэкенд падает с `ModuleNotFoundError`.

## Причина
`git pull` **не восстанавливает удалённые файлы** — он только обновляет существующие.

## Решение 1: Восстановить через git reset

```bash
cd /var/www/beauty-specialist
git reset --hard HEAD
```

## Проблема 2: deploy.yml использует passlib
Файл `deploy.yml` строит суперпользователя через `passlib`, который несовместим с bcrypt >= 4.0.

## Решение 2: Обновить deploy.yml (локально)
Заменить в deploy.yml:
- `from passlib.context import CryptContext` → `import bcrypt`
- `pwd_context.hash(password)` → `bcrypt.hashpw(password.encode(), bcrypt.gensalt(rounds=12)).decode()`

## Полный порядок действий

### На сервере (если бэкенд ещё не работает):
```bash
cd /var/www/beauty-specialist
git reset --hard HEAD
systemctl restart beauty-backend
journalctl -u beauty-backend -n 30 --no-pager
```

Если ошибка — покажи вывод `journalctl`.

### Локально (я сделаю):
- Обновлю `deploy.yml` для bcrypt
- Закоммичу и запушу
- На сервере: `git pull && systemctl restart beauty-backend`
