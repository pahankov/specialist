# План: Автоматическая синхронизация БД при пуше

## Проблема
При каждом изменении моделей нужно вручную:
1. Применять миграции на сервере
2. Создавать суперпользователя
3. Фиксить timezone-ошибки

## Решение

### 1. Починить модели (timezone)
**Файлы:** `online-booking/backend/app/models/*.py`

Во всех моделях заменить `Column(DateTime, ...)` на `Column(DateTime(timezone=True), ...)`:

- `app/models/user.py` — `created_at`, `updated_at`
- `app/models/master_profile.py` — `created_at`, `updated_at`
- `app/models/client_profile.py` — `created_at`, `updated_at`
- `app/models/service.py` — `created_at`, `updated_at`
- `app/models/appointment.py` — `appointment_date`, `created_at`, `updated_at`
- `app/models/working_hour.py` — `created_at`
- `app/models/audit_log.py` — `created_at`
- `app/models/blocked_slot.py` — `created_at`, `start_dt`, `end_dt`
- `app/models/refresh_token.py` — `created_at`, `expires_at`
- `app/models/otp_code.py` — `created_at`, `expires_at`
- `app/models/review.py` — `created_at`, `updated_at`

### 2. Создать миграцию
```bash
cd online-booking/backend
alembic revision --autogenerate -m "fix timezone in datetime columns"
```

Проверить сгенерированный файл — должен менять тип колонок на `TIMESTAMP WITH TIME ZONE`.

### 3. Обновить deploy.yml
Файл: `.github/workflows/deploy.yml`

Добавить в скрипт деплоя:
- `alembic upgrade head` — автоприменение миграций
- Создание/обновление суперпользователя `pahankov@mail.ru`
- Запуск `seed_production.py` (если БД пустая)

### 4. Создать seed_production.py
Файл: `online-booking/backend/seed_production.py`

```python
"""Seed production data if DB is empty."""
import asyncio
from sqlalchemy import select, text
from app.database import AsyncSessionLocal

async def seed_if_empty():
    async with AsyncSessionLocal() as session:
        result = await session.execute(select(text('count(*)')).select_from(text('users')))
        if result.scalar() > 0:
            return  # Данные есть, пропускаем
        from seed_test_data import create_seed_data
        await create_seed_data()

if __name__ == "__main__":
    asyncio.run(seed_if_empty())
```

### 5. Итоговый workflow при разработке

```
1. Изменил модель (добавил поле)
2. alembic revision --autogenerate -m "add field_name"
3. Проверил файл миграции
4. git add + commit + push origin main
5. GitHub Actions → автоматически:
   - git pull
   - alembic upgrade head (миграции)
   - создаёт суперпользователя
   - собирает frontend
   - перезапускает сервисы
```

**Никаких ручных действий на сервере больше не нужно.**
