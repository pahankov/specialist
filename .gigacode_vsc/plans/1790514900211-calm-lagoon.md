## Архитектура

```
beauty-specialist.ru
    │
    ├── Nginx (port 80→443, SSL)
    │   ├── /api/* → http://localhost:8000 (Backend FastAPI)
    │   └── /*     → /var/www/beauty-specialist/frontend/dist (Frontend static)
    │
    ├── Backend: FastAPI + uvicorn (port 8000, systemd)
    ├── Frontend: React → static files (Nginx раздаёт)
    ├── PostgreSQL 16 (~50-80 МБ RAM)
    ├── Let's Encrypt (SSL)
```

**Потребление RAM:**
- Nginx: ~3-5 МБ
- PostgreSQL: ~50-80 МБ
- Python/uvicorn: ~80-120 МБ
- Система: ~100 МБ
- **Итого в работе: ~250-350 МБ** (из 1 ГБ — OK)
- **Swap: 2 ГБ** (защита от OOM при пиковой нагрузке)

## Шаг 0: Swap 2 ГБ

```bash
# Создание swap-файла
dd if=/dev/zero of=/swapfile bs=1M count=2048
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile

# Постоянная настройка
echo '/swapfile none swap sw 0 0' >> /etc/fstab

# Настройка swappiness
echo 'vm.swappiness=10' >> /etc/sysctl.conf
sysctl -p
```

## Шаг 9: Настройка Nginx

### 9.1 Установка

```bash
apt install -y nginx
```

### 9.2 Конфигурация

```bash
cat > /etc/nginx/sites-available/beauty-specialist << 'EOF'
# Redirect HTTP → HTTPS
server {
    listen 80;
    server_name beauty-specialist.ru www.beauty-specialist.ru;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name beauty-specialist.ru www.beauty-specialist.ru;

    # SSL
    ssl_certificate /etc/letsencrypt/live/beauty-specialist.ru/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/beauty-specialist.ru/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    # Frontend - static files
    location / {
        root /var/www/beauty-specialist/frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    # Backend API
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # Swagger docs (только для разработки)
    location /docs {
        proxy_pass http://127.0.0.1:8000/docs;
        proxy_set_header Host $host;
    }

    # Health check
    location /health {
        proxy_pass http://127.0.0.1:8000/health;
        proxy_set_header Host $host;
    }
}
EOF

# Активируем сайт
ln -s /etc/nginx/sites-available/beauty-specialist /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default

# Тест и перезапуск
nginx -t && systemctl restart nginx
systemctl enable nginx
```

## Шаг 12: CI/CD — Автодеплой при пуше

### 12.1 GitHub Secrets

Добавить в GitHub repo → Settings → Secrets:
```
SERVER_HOST=194.226.123.249
SERVER_USER=deploy
SERVER_SSH_KEY=<private_ssh_key>
```

### 12.2 Настройка SSH на сервере

```bash
# На сервере (от root):
mkdir -p /home/deploy/.ssh
chmod 700 /home/deploy/.ssh

# Копирование публичного ключа (сгенерировать на локальной машине)
# ssh-keygen -t ed25519 -C "github-actions"
echo "<public_key>" > /home/deploy/.ssh/authorized_keys
chmod 600 /home/deploy/.ssh/authorized_keys
chown -R deploy:deploy /home/deploy/.ssh
```

### 12.3 Workflow deploy.yml

```yaml
name: Deploy

on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Deploy to server
        uses: appleboy/ssh-action@v1.0.0
        with:
          host: ${{ secrets.SERVER_HOST }}
          username: deploy
          key: ${{ secrets.SERVER_SSH_KEY }}
          script: |
            cd /var/www/beauty-specialist
            git pull origin main

            # Backend
            cd online-booking/backend
            python3.12 -m venv venv
            source venv/bin/activate
            pip install -r requirements.txt
            alembic upgrade head

            # Frontend
            cd ../frontend
            npm ci
            npm run build
            cp -r dist/* /var/www/beauty-specialist/frontend/dist/

            # Restart
            systemctl restart beauty-backend
            systemctl restart nginx
```
